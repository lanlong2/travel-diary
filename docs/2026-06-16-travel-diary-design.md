# 旅行日记 — 设计文档

> 2026-06-16 · 私人纪念册 · 温暖手账风

---

## 一、项目定位

为中国情侣设计的私人旅行纪念网站。两人共享，用共享密码登录，记录一起走过的城市、拍过的照片、写下的留言。

**核心体验：** 打开网站 → 看到中国地图上的足迹 → 点击城市看回忆 → 上传新照片写留言。

---

## 二、目标用户 & 设备

- **用户：** 两人（情侣），共享密码登录
- **设备：** iPhone（主要）+ 电脑（整理/浏览）
- **场景：** 旅行途中手机拍照记录 / 回家后电脑整理回忆

## 四、页面结构

### 4.1 首页 · 中国足迹地图

```
┌────────────────────────────┐
│  ❤️ 我们在一起 X 天了        │  ← 从 2024.11.08 起计，每日自动更新
│                            │
│  🗺️ 高德地图（铺满）         │  ← 支持缩放、拖拽
│    📍 去过城市 → 实心标记    │  ← 不同颜色代表不同旅行
│    📍 想去城市 → 虚线圆圈    │
│    点击标记 → 弹出城市卡片   │  ← 去过几次、最新照片、查看详情
│                            │
│  📖 最近旅行（横向滑动卡片）  │
│  ┌────┐ ┌────┐ ┌────┐    │
│  │旅行│ │旅行│ │旅行│    │
│  └────┘ └────┘ └────┘    │
│                            │
│  [+ 开始新旅行] FAB         │
│                            │
│  🗺️ 📖 ➕ 💌 ⚙️ 底部导航    │
└────────────────────────────┘
```

### 4.2 旅行详情页

- **封面大图** — 旅行主图 + 标题 + 日期
- **路线地图** — 小地图上连线串起本次旅行所有城市
- **照片瀑布流** — 三列网格，点击放大，每张可配留言
- **添加按钮** — 两人都能随时添加照片

### 4.3 添加记录页

- 上传照片（拍照或选图）
- 选择城市（自动定位或搜索）
- 选择属于哪次旅行（或新建）
- 写留言
- 保存

### 4.4 登录页

- 输入共享密码
- 验证通过后进入首页

## 五、数据模型（Supabase）

### trips 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| title | text | 旅行标题（如"川西环线"） |
| cover_photo | text | 封面图 URL |
| start_date | date | 开始日期 |
| end_date | date | 结束日期 |
| created_by | text | 创建者（"我"/"她"） |
| created_at | timestamptz | 创建时间 |

### trip_cities 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| trip_id | uuid → trips.id | 所属旅行 |
| city_name | text | 城市名 |
| lat | float | 纬度 |
| lng | float | 经度 |
| sort_order | int | 路线顺序 |

### photos 表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| trip_id | uuid → trips.id | 所属旅行 |
| city_name | text | 所在城市 |
| image_url | text | 照片 URL（Supabase Storage） |
| note | text | 留言/笔记 |
| author | text | 作者（"我"/"她"） |
| created_at | timestamptz | 创建时间 |

### auth 表（Supabase 内置）

- 使用共享密码方案：在 Supabase 中创建一个共享账号，两人共用
- 登录页输入密码 → Supabase Auth 验证 → 获取访问令牌

## 六、技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端框架 | React + Vite + TypeScript | 现代前端，快速开发 |
| 样式 | Tailwind CSS | 响应式，温暖手账风定制 |
| 地图 | 高德地图 JS API 2.0 | 中国地图最精确，免费 |
| 后端 | Supabase | 数据库 + 文件存储 + 认证 |
| 部署 | Vercel | 免费 HTTPS，自动 CI/CD |
| PWA | vite-plugin-pwa | 可添加到手机主屏幕 |

---

## 七、安全设计

- 共享密码登录，Supabase Auth 处理认证
- 照片存储使用 Supabase Storage RLS 策略（仅认证用户可访问）
- 数据库 RLS：仅登录后可读写
- 不外泄任何数据
